# Glossary

| Term               | Definition                                                                                                                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **System**         | A named star system rendered at a given `(x, y)` world coordinate on the map. Called a planet in v0.                                                                                                                                                                |
| **Spacelane**      | A named route made of one or more segments, each with an origin, a destination, and a color.                                                                                                                                                                        |
| **Priority order** | The order of the `systems` and `spacelanes` arrays, highest priority first. It decides what is drawn when not everything fits.                                                                                                                                      |
| **Culling**        | Choosing which systems, labels, and lane segments to draw for the current view, walking in priority order and hiding collisions and anything over the limits.                                                                                                       |
| **Color**          | Any CSS color string supplied by the consumer. There is no color enum.                                                                                                                                                                                              |
| **Zoom**           | The scale of the view in screen pixels per world unit. Higher values zoom in.                                                                                                                                                                                       |
| **Bounds**         | The bounding box (`min` and `max` points) of the content area. Defaults to the extent of the data.                                                                                                                                                                  |
| **Viewport**       | The camera: a `center` point in world coordinates and a `zoom`.                                                                                                                                                                                                     |
| **Canvas**         | The generic pan and zoom surface that `GalaxyMap` draws on. It has no galaxy concepts.                                                                                                                                                                              |
| **Consumer**       | A React application or developer that installs and uses `@outoforbitdev/galaxy-map` as a dependency. See [Andrea the Atlas Builder](./personas/persona-andrea-the-atlas-builder.md) and [Gavin the Game Developer](./personas/persona-gavin-the-game-developer.md). |
| **End user**       | A person interacting with the embedded map in a consuming application. See [Arlo the Atlas User](./personas/persona-arlo-the-atlas-user.md) and [Priya the Player](./personas/persona-priya-the-player.md).                                                         |
| **Contributor**    | A developer or AI agent who maintains or extends this library's internals. See [Casey the Contributor](./personas/persona-casey-the-contributor.md).                                                                                                                |
| **ood-react**      | The `@outoforbitdev/ood-react` peer library that provides base component utilities used internally by this library.                                                                                                                                                 |
